# BLACKBOX: AI Agent Flight Recorder

> A flight recorder + investigation system for AI agents. Record every step, diagnose failures with hybrid analysis, replay with interventions, and evaluate diagnosis accuracy.

⚠️ **All demo data is synthetic and generated by deterministic code.**

## What is BLACKBOX?

BLACKBOX captures comprehensive execution traces of AI agent runs and provides a multi-layered investigation toolkit:

1. **WHAT HAPPENED** — Full execution timeline with step-by-step recording
2. **WHERE DID IT DIVERGE** — Comparison with successful runs to find the first meaningful divergence
3. **WHY IS THAT STEP SUSPICIOUS** — Hybrid diagnosis combining rules, anomaly detection, learned ranking, dependency analysis, and historical patterns
4. **WHAT EVIDENCE SUPPORTS IT** — Transparent breakdown of each diagnosis signal
5. **WHAT IF WE CHANGE IT** — Replay Lab for re-executing with interventions and side-effect suppression
6. **DID THE CHANGE FIX IT** — Diff view of original vs replayed outputs
7. **HOW ACCURATE IS BLACKBOX** — Evaluation Studio with Top-1, Top-3, and MRR metrics against labeled benchmarks

## Diagnosis Engine

The Hybrid Diagnosis system combines five independent signals:

| Signal | Weight | Type | Description |
|--------|--------|------|-------------|
| Rule Match | 0.30 | Deterministic | Constraint violations, type mismatches, budget overflows |
| Anomaly Signal | 0.20 | Statistical | Z-score analysis on duration, output size vs. historical |
| Learned Ranker | 0.20 | ML (Logistic Regression) | Trained on labeled synthetic failure data |
| Dependency Impact | 0.15 | Graph Analysis | Downstream failure propagation scoring |
| Historical Evidence | 0.15 | Similarity | Cosine similarity to known failure patterns |

**Suspicion Score** is a heuristic ranking score (0–100), not a probability.

## Demo Agent: TravelPlanner

The flagship demo traces a Paris 7-day budget trip planning agent with an **arithmetic duplication bug**: the `budget_calculation` step adds accommodation cost twice, causing the budget to be exceeded and the run to fail.

## Quick Start

### Backend
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # macOS/Linux
pip install -r requirements.txt
python main.py
# API at http://localhost:8000
```

### Frontend
```bash
cd frontend
npm install
npm run dev
# UI at http://localhost:3000
```

## Tech Stack

**Frontend:** Next.js 14 (App Router), React, TypeScript, Tailwind CSS, shadcn/ui, Lucide, Framer Motion, React Flow, Recharts, TanStack Query, Zod

**Backend:** Python 3.11+, FastAPI, Pydantic v2, SQLAlchemy 2, SQLite, NumPy, pandas, scikit-learn

## Offline Operation

BLACKBOX works fully offline with no API key required. All diagnosis is performed locally using deterministic rules, statistical analysis, and a locally-trained ML ranker. External LLMs are an optional explanation layer only.
